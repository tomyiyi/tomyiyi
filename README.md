### 💡 工程哲学与设计法则 (Philosophy)

> *“最好的代码是没有写出来的代码。真正的完美，不是不能再加什么，而是无法再删减什么。”*

1. **图文解耦**：扩散模型 100% 专注于光影、材质与留白，代码 100% 专注于栅格对齐、字阶与清晰字形。
2. **验证胜于空谈**：可落地、可运行、可交付的高清成图与真实端到端自动化，胜过所有纸面规划。
3. **极简自包含与高便携**：拒绝臃肿沉重的环境依赖，跨设备一键拉取即刻启动，开箱即用。
