### 🧭 关于我 (About Me)

- 🔭 **当前聚焦**：构建**低摩擦、可验证、零重依赖**的 AI Agent 工具链与多模态视觉排版引擎。
- 🧩 **核心方向**：
  - **AI Agent 工程化**：多账号隔离与无缝上下文接力、Agent 拒答死胡同恢复契约、桌面客户端去摩擦治理；
  - **多模态与视觉排版**：图文解耦生成范式（AI 留白底图 + 矢量精确排版 + 无头浏览器光栅化）、PPT 多形态物料流水线；

- 💼 **开放合作**：欢迎交流前沿 AI 产品架构、多模态内容管线与 Agent 自动化落地。

### 💡 工程哲学 (Engineering Philosophy)

> *“最好的代码是从未写出来的代码。真正的完美，不是不能再加什么，而是无法再删减什么。”*

1. **物理落地优先**：可运行、可复现、带回归测试的真实代码与产物，胜过一切纸面方案。
2. **图文与职责解耦**：让生成模型专注光影与创意，让确定性代码专注栅格、排版、校验与安全边界。
3. **极简自包含**：优先原生与标准库，拒绝臃肿重依赖，做到跨设备一键拉取、开箱即用。
